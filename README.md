# Kasmate — struktur lokal

Buka index.html untuk memulai. Halaman menggunakan penyimpanan browser (localStorage/sessionStorage), tanpa koneksi ke API/database.

## Halaman
- index.html — Home
- about.html — About
- dashboard.html — Dashboard dan data siswa
- transactions.html — Riwayat transaksi dan pengeluaran
- settings.html — Tema, bahasa, profil, dan kata sandi
- login.html — Login lokal
- register.html — Registrasi lokal

## Aset bersama
- css/style.css — seluruh gaya dan responsive layout
- js/app.js — navigasi, autentikasi lokal, terjemahan, dashboard, transaksi, dan pengaturan
- assets/kasmate-logo.png — logo

Edit HTML untuk mengubah konten halaman tertentu, stylesheet untuk tampilan bersama, dan app.js untuk interaksi.
